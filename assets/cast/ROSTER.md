# 여성 입주자 이미지 풀 (30명)

`scripts/cast-roster.mjs`가 woman-05 ~ woman-30의 나이·라벨·인상 설명(프롬프트)을 갖고 있고, `cast.js`의 `CAST`와 같은 내용이어야 합니다(`tests/cast.test.mjs`가 확인).

- woman-01 ~ 04: 기존 이미지 유지.
- woman-05 ~ 08: 서로 구분되는 새 인상으로 재생성 완료.
- woman-09 ~ 30: 신규 이미지 22장 생성 완료. 헤어 색·길이·질감, 얼굴형, 피부톤, 체형, 안경·피어싱·교정기 같은 소품, 옷 색을 서로 다르게 지정했습니다.

모델은 `qwen/qwen-image-2.1-turbo`(OpenRouter Image API)이며 `AGENTS.md` 지침을 따릅니다. 배경은 UI 타일 색과 맞춘 단색 `#26233D`로 요청하고, 기존 투명 배경 이미지와 함께 쓰입니다. 모든 인물은 가상의 성인이며 가리는 홈웨어를 입은 정면 전신으로 생성합니다.

## 생성

```sh
npm run cast:generate -- --redo
```

실제 파일이 있는 인물만 `cast-ready.js`에 등록되어 배정 대상이 됩니다. 생성 결과가 마음에 들지 않으면 `--only woman-12 --force`로 한 명만 다시 만들 수 있습니다.

## 2026-10-27 적용

실제 여성 이미지 30장이 모두 준비되어 배정됩니다. 20~49세를 지원하며, 40대는 woman-12(44), 17(40), 20(46), 23(42), 24(48), 26(43), 27(49)입니다. 기존 woman-01~04는 유지했습니다. 새 입주자는 현재 입주자·지원자와 겹치지 않는 준비된 얼굴을 먼저 배정하고, 그 얼굴과 두 살 이내인 나이를 사용합니다. 기존 저장에 있는 나이·인물 인덱스는 유지합니다.

`cast-preview.html`에서 전체 30명과 연령대별 이미지를 비교할 수 있습니다. 원본 프롬프트는 `scripts/cast-roster.mjs`의 `subject`와 `promptFor`에 보관됩니다. OpenRouter의 `qwen/qwen-image-2.1-turbo`로 개별 생성했으며 키는 포함하지 않습니다.

## 제외된 이미지

사용자 요청으로 woman-01·02·04·12를 삭제했습니다. 현재 활성 풀은 26명이며 `cast-retired.js`가 배정·이미지 재생성·사진 요청에서 이 네 파일을 제외합니다. 기존 저장의 해당 외모만 활성 이미지로 전환합니다. 삭제된 원본과 파생 이미지는 공개하지 않습니다.
