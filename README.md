# ROOM19 · 용산의 작은 생활들

서울 용산의 5층 × 4호실 오피스텔을 운영하는 PC 브라우저용 GUI 생활 시뮬레이션 MVP입니다. 20개 호실을 정면 단면으로 보고 클릭해 원룸과 닫힌 욕실을 확대합니다. ImageGen으로 제작한 실사 배경·실내·외관·성인 캐릭터를 레이어로 합성합니다.

## 실행

Node.js 20.11 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 **http://127.0.0.1:4173** 을 엽니다. 권장 화면은 **1440×900 이상**, 최소 너비 1100px입니다. 창이 좁다면 브라우저 전체 화면 또는 게임의 ⛶ 버튼을 사용하세요. 모바일 레이아웃은 현재 대상이 아닙니다. 다른 정적 웹 호스팅에서도 프로젝트 폴더를 그대로 제공할 수 있습니다.

```sh
npm test
```

## 플레이

- **방 클릭**: 해당 방을 확대합니다. 확대 중 시간은 멈추며, 닫으면 기존 속도로 돌아갑니다.
- **입주 심사**: 사진 카드의 생활 성향, 근무시간, 월세 예산, 보증금을 보고 공실을 골라 승인하거나 거절합니다. 공실을 클릭하면 월세와 보증금을 변경할 수 있습니다. 성별과 나이는 캐릭터 소개 정보이며 승인 조건으로 사용하지 않습니다.
- **생활 관찰**: 사람의 등장·외출, 주방과 책상 위치, 수면 아이콘, 방문객 등장, 닫힌 욕실과 프라이버시 표시로 상태를 확인합니다. 사적 욕구는 수치와 비공개 상태로만 표현하며, 노출과 성행위 이미지는 없습니다. 모든 NPC는 20–39세의 가상 한국 성인입니다.
- **관리**: 고장 난 방을 확대해 ⚒ 버튼으로 수리합니다. 건물 관리 패널에서 민원을 중재하고 방음·급배수·라운지 시설을 투자합니다.
- **시간**: 정지 / 1× / 4× / 12× 또는 다음 날 아침 버튼을 사용합니다. 1×에서 실제 1.5초마다 게임 10분, 백그라운드에서는 시간이 멈춥니다.
- **단면/외관**: 무드용 외관 이미지와 실제 20개 인터랙티브 호실을 전환합니다. 외관 이미지는 생성된 장식 플레이트로 창의 배치가 실제 호실 그리드와 정확히 일치하지 않을 수 있습니다.
- **저장**: 브라우저 로컬 저장, JSON 내보내기와 불러오기를 지원합니다. 서버 계정과 클라우드 저장은 없습니다. 새 게임은 확인 후 진행을 초기화합니다.

## 시뮬레이션과 경제

초기 입주자는 9명이며 고정 100명 풀을 사용하지 않습니다. 공실이 있을 때 지원자를 생성하며 신청서는 4일 후 만료됩니다. 근무 시간표, 휴일, 활력·허기·위생·교류·사적 욕구가 행동을 결정합니다. 저녁 교류로 친밀도가 쌓이면 서로 싱글인 성인 NPC가 연인이 될 수 있습니다. 생활 성향 차이는 소음 민원으로 이어지고, 만족도가 3일 연속 25 미만이면 퇴거합니다.

금액 단위는 만 원입니다. 월세는 매일 월세/30씩 발생하고 운영비 24만 원을 차감합니다. 보증금은 별도 예치 장부에 기록해 운영 자금에 더하지 않으며 퇴거 시 예치 잔액에서 반환합니다. 수리와 업그레이드는 즉시 비용이 발생합니다. 업그레이드는 각 3단계입니다. 자금이 음수가 되어도 관찰을 계속할 수 있으며 현재 파산 엔딩은 없습니다.

## 구조

- `sim.js`: 브라우저와 독립된 순수 상태 시뮬레이터, 저장/복원, 입주·정산·관계·시설 로직
- `app.js`: 클릭 조작, 시간 제어, 패널과 호실 확대, 자동 저장
- `art.js`: 실사 이미지와 투명 캐릭터를 합성하는 그래픽 레이어
- `style.css`, `desktop.css`: 기본 스타일과 PC 게임 화면
- `server.mjs`: 로컬 정적 서버(개발·개인 플레이용)
- `assets/`: 프로젝트에 포함된 ImageGen 이미지와 제작 기록
- `tests/`: Node 내장 테스트 러너로 검증하는 핵심 게임 규칙

## 현재 범위

실사 기반 2D 레이어 MVP이며 자유 이동 3D 게임이 아닙니다. NPC 데이터는 무작위 생성되지만 외모는 8종 리소스를 재사용합니다. 실내 구조도 공통 리소스입니다. 인물은 상태에 따라 위치·등장·표시가 바뀌며 완전한 보행·식사·수면 프레임 애니메이션은 다음 단계입니다. 욕실 내부는 보여주지 않습니다. 방문객은 이름 없는 외부 친구/연인 상태이며 외부 도시 전체를 시뮬레이션하지 않습니다. 증축·가구 편집·별도 퀘스트·서버 멀티플레이는 미구현입니다. 자세한 후속 계획은 [ROADMAP.md](ROADMAP.md)에 정리했습니다.

## UI 참고와 자산

2026년 공개 브라우저 게임 [Cityblock](https://eckladen.itch.io/cityblock)의 데스크톱 중심 직접 선택 방식과 [NIMBUS Redux](https://mount-fuji-software.itch.io/nimbus-redux)의 즉시 플레이·PC 저장 흐름을 참고했습니다. 코드나 아트를 복제하지 않았습니다. 이 프로젝트의 원룸·인물·도시·건물 이미지는 내장 ImageGen으로 새로 생성했습니다. 생성 프롬프트와 자산 설명은 [assets/PROVENANCE.md](assets/PROVENANCE.md)에 있습니다.

외부 네트워크는 Google Fonts 웹폰트에만 선택적으로 사용하며, 차단되어도 기본 한글 글꼴로 플레이할 수 있습니다. 외부 API 키, 게임 백엔드, 유료 서비스 연결은 필요하지 않습니다.
