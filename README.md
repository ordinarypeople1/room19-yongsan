# ROOM19 · 용산의 작은 생활들

서울 용산의 5층 × 4호실 오피스텔에서 성인 입주자들의 일상을 지켜보는 PC용 힐링 방치 게임입니다. 퀘스트, 수익 목표, 제한 시간, 파산 엔딩 없이 각자의 생활과 관계가 흘러갑니다.

## 실행

Node.js 20.11 이상에서 패키지 설치 없이 `npm start`를 실행하고 http://127.0.0.1:4173 을 엽니다. 권장 화면은 1440×900, 최소 너비는 1024px입니다. `npm test`로 테스트 19개를 실행합니다.

## 플레이

첫 화면에는 20개 방과 생활하는 사람, 시간 제어만 표시합니다. 인물 대사·욕구 게이지·고정 정보 패널은 없습니다. 방을 클릭하면 확대 화면에서 인물 정보, 욕구, 취향, 임대 조건을 확인합니다. 확대 중에도 인물과 시간이 계속 움직입니다. Space로 일시 정지/재개할 수 있습니다.

상단 입주 심사·집 돌보기·저장을 누르면 필요할 때만 운영 패널이 열립니다. 기존 버전의 저장 파일도 이어서 사용할 수 있습니다. 세이브 파일 내보내기/불러오기와 자동 저장을 지원합니다.

## 자율적인 생활

- 모든 인물은 20–39세의 가상 한국 성인입니다. 고정 100명 풀 없이 지원자를 무작위 생성합니다.
- 인물은 시간표와 욕구에 따라 출퇴근, 수면, 샤워, 속옷 갈아입기, 식사, 청소, 빨래, 독서, 음악 감상, 스트레칭, 차 마시기, 휴대폰 사용, 친구·연인 방문과 비공개 사적 시간을 보냅니다.
- 생활복과 외출복을 구분하고, 인물이 방 안의 장소를 경로에 따라 계속 이동합니다. 출근할 때는 방 밖으로 나가고, 귀가하면 같은 경계에서 돌아옵니다.
- 인물은 2D 사진 기반 레이어를 합성한 스프라이트이며 보행·작업·앉기·스트레칭 자세를 조합합니다. 모든 생활 동작을 별도 촬영한 연속 프레임이나 완전한 3D 인체 시뮬레이션은 아닙니다.
- 샤워와 옷 갈아입기는 방 전체를 덮지 않습니다. 신체 세부가 없는 비식별 형태에 강한 블러와 수증기를 적용합니다. 원본 노출 이미지나 성행위 이미지는 포함하지 않습니다. 샤워용 이미지 생성은 도구에서 차단되어 비식별 CSS 효과를 사용합니다.
- 친밀도가 쌓이면 성인 NPC끼리 연인이 되고 방문과 함께하는 시간이 늘어납니다.

## 빈 방과 취향

공실에는 침대·책상·의자·장식이 없습니다. 주방과 욕실 같은 기본 붙박이 설비만 남아 있습니다. 입주하면 인물의 성향에 따라 미니멀·따뜻한 내추럴·개인 작업실의 세 가지 실사 실내 중 하나가 적용됩니다. 퇴거 후에는 다시 빈 방으로 돌아갑니다. 자유 가구 배치 에디터는 아직 없습니다.

## 가구와 서랍 탐색

입주자가 실제로 방 밖으로 나간 뒤 방을 클릭하면 옷장, 책상 서랍, 침대 옆 서랍, 주방 수납장의 버튼이 표시됩니다. 클릭해 평범한 의류와 속옷·양말, 책, 노트, 편지, 생활용품 같은 가상의 소지품을 살펴볼 수 있습니다. 귀가하면 탐색이 닫힙니다. 실존 인물의 정보나 실제 파일을 읽는 기능은 없습니다.

## 편안한 방치 진행

기본 모드는 `cozy`입니다. 만족도가 낮다는 이유로 강제 퇴거하지 않으며, 작은 고장은 다음 일일 점검 때 자동 수리되고 오래된 민원은 완화됩니다. 적립 자금의 하한을 두어 경제적 실패를 강요하지 않습니다. 입주자 승인과 집 돌보기는 원하는 때 개입할 수 있습니다.

1×는 실제 6초마다 게임 10분입니다. 인물 이동은 별도의 연속 프레임 루프로 실행하며 4×/12×에서는 이동과 생활 시간도 빨라집니다. 창을 숨기거나 닫아 둔 시간은 돌아왔을 때 계산하며, 한 번에 최대 게임 7일까지 진행합니다. 백그라운드 탭을 계속 고속 렌더링하지 않습니다. 브라우저 로컬 저장만 제공하며 서버 계정은 없습니다.

## 소스

- `sim.js`: 생활·관계·주택 상태, 편안한 기본 모드, 오프라인 진행과 저장 검증
- `motion.js`: 연속 이동, 생활 장소와 자세, 취향 선택
- `live-app.js`: 클릭 조작, 상세·운영 화면, 저장과 인물 뷰 연결
- `live-art.js`, `live.css`: 이미지 레이어와 인물 조합, Pretendard와 큰 글씨
- `objects.js`: 외출 여부에 따른 가구 탐색과 가상 소지품
- `server.mjs`: 개인 플레이용 로컬 정적 서버
- `tests/`: 생활·이동·방치·소지품의 19개 자동 테스트

추가 엔진이나 유료 API 없이 브라우저의 연속 프레임 렌더링을 사용합니다. 기존 0.1 코드와 이미지는 호환 이력용으로 남아 있지만 진입점은 `live-app.js`입니다. 현재 사용되는 이미지는 `characters.png`, `homewear-v2.png`, `empty-v2.png`, `minimal-v2.png`, `warm-v2.png`, `creative-v2.png`입니다.

폰트는 [Pretendard 공식 배포](https://github.com/orioncactus/pretendard)의 v1.3.9 동적 서브셋 CDN을 사용합니다. 인터넷 연결이 없으면 시스템 한글 글꼴로 대체됩니다. 생성 이미지와 프롬프트 기록은 [assets/LIVE-ASSETS.md](assets/LIVE-ASSETS.md), 후속 계획은 [ROADMAP.md](ROADMAP.md)에 있습니다.
