# ROOM19 · 용산의 작은 생활들

서울 용산의 여성 전용 숙소에서 성인 여성 이웃들의 하루를 지켜보고, 이야기를 나누고, 생활에 개입하는 개인 플레이용 게임입니다.

## 1.0 · Midnight — 캐릭터챗 UI, 입력중 표시, 방 촬영, 입주자 30명 풀

- 다크 모드 기준으로 UI를 다시 만들었습니다(`midnight.css`). 남보라 배경에 보라→분홍 그라데이션, 유리 질감 카드, 말풍선 대화, 탭 세그먼트 컨트롤을 쓰고 이전의 녹색·금색 계열은 모두 덮어씁니다. 버튼은 눌림·물결(`fx.js`)·호버 광택을 갖고, 대화창·사진 완성·토스트에는 스프링 등장 효과가 있습니다. `prefers-reduced-motion`에서는 움직임을 줄입니다.
- 대화는 말풍선으로 표시합니다. 보낸 말이 오른쪽에 먼저 나타나고 "전송됨" 아래에 입주자의 `· · ·` 입력 중 표시가 이어지다가 답장이 도착하면 바뀝니다. AI 응답이 아주 빨라도 최소 0.9초는 입력 중으로 보입니다.
- 행동 기록의 `· 비공개` 표기와 "자세한 내용은 비공개다" 문장을 없앴습니다. 샤워·옷 갈아입기·혼자만의 시간은 장면 문장과 `사적인 시간` 태그로, 연인과의 밤과 늦은 밤 혼자만의 시간은 `19+` 태그와 분홍 강조로 표시합니다. 19+ 문장은 8종(연인)·4종(혼자)을 시각·연인 이름에 따라 고르며, 분위기와 감각까지만 쓰고 신체 부위·행위의 직접 묘사는 하지 않습니다.
- 입주자 이미지 풀을 8명에서 30명으로 늘리도록 구조를 바꿨습니다. 스펙은 `scripts/cast-roster.mjs`, 생성은 `npm run cast:generate`(Qwen Image 2.1 Turbo), 실제 파일이 있는 인물만 `cast-ready.js`에 등록되어 배정됩니다. 자세한 절차는 `assets/cast/ROSTER.md`를 참고하세요.
- 방 상세에서 방 사진을 누르면 크게 보고, `촬영` 버튼 또는 사진 탭에서 방 안 사진을 생성합니다. 방 취향 3종과 시간대 조명이 프롬프트에 반영되고, 입주자가 외출·수면·사적인 시간이면 촬영하지 않습니다. 생성 사진은 입주자별 최근 12장까지 이 브라우저에 보관합니다.

## 0.9 · 큰 프로필, 분 단위 행동 기록, 입주자별 AI 대화

- 화면 전반의 글자와 조작 버튼을 확대했습니다. 방 상세에는 큰 프로필 사진, 나이·직업·성격·취미를 표시합니다.
- 방을 열면 분 단위 행동 기록이 먼저 표시됩니다. 대화와 기억은 별도 탭에서 볼 수 있으며, 메시지를 보내면 대화 탭으로 이동합니다.
- 실제 1.8초마다 게임 1분이 흐르고 그 시점의 활동을 기록합니다. 욕구와 주요 행동 판단은 기존 10분 간격을 유지합니다. 각 입주자의 최근 240분을 저장합니다.
- 샤워·옷 갈아입기는 사적인 기록으로, 연인과의 친밀한 시간과 늦은 휴식 중 확률적으로 나타나는 개인 시간은 19+ 비공개 기록으로 표시합니다. 내용은 비노골적이며 행동 상태에 맞을 때만 생성됩니다. 사적인 기록만 필터링할 수 있습니다.
- AI에는 해당 입주자의 성격·취미·가치관·말투, 현재 시간·행동·욕구·친밀감, 최근 행동 8개, 함께한 기억 8개, 이전 대화 4개를 전달합니다. 다른 입주자의 대화는 전달하지 않습니다.
- 공개 GitHub Pages 화면은 `ai-config.js`의 전용 AI 서버 주소로 연결합니다. OpenRouter 키는 별도 Sites 서버의 비밀 환경 설정에만 보관합니다. GitHub와 브라우저에는 포함하지 않습니다.
- 지정된 `:free` 엔드포인트가 사용 종료를 반환해, 사용자 승인으로 `cognitivecomputations/dolphin-mistral-24b-venice-edition` 유료 버전을 사용합니다.
- AI 서버는 허용 출처 확인, 15분짜리 서명 세션, IP별·서버 인스턴스별 호출 제한, 요청 크기·응답 길이·동시 요청 제한을 적용합니다. 인스턴스 제한은 계정 전체의 영구 비용 한도가 아닙니다. 계정 비용 한도는 OpenRouter에서 별도로 관리합니다.

## 0.8 · 여성 전용 숙소

- 초기 입주자와 신규 신청자는 모두 20–39세 여성입니다.
- 여성 인물 이미지 8종을 나이대에 맞춰 배정합니다. 표시 나이를 유지하며 이미지 기준 나이와 최대 2세 차이인 후보 중 중복이 적은 이미지를 사용합니다.
- 이전 저장을 불러오면 남성 입주자·신청자는 여성 이름과 이미지로 전환합니다. 진행 상황, 나이, 직업, 계약, 관계와 기억은 유지됩니다.
- 새로 생성한 21·26·34·39세 여성 이미지의 내장 ImageGen 프롬프트는 `assets/cast/WOMEN-ONLY.md`에 있습니다.

## 0.7 · Horizon & Stories

- 가로로 펼쳐진 도시 전경 가운데 ROOM19 한 건물의 5층 × 4개 방을 표시합니다.
- 방 타일에는 입주자 얼굴을 크게 표시합니다. 외출·사적 시간에는 사진을 어둡게 표시하고, 새 답장과 수리 요청에는 작은 표시가 생깁니다.
- 마우스 오버 또는 키보드 초점으로 이름·나이·직업·현재 행동을 확인합니다. 클릭하거나 Enter를 누르면 방 상세를 엽니다. 터치에서는 바로 상세를 엽니다.
- 상세에는 기존 방 내부 스틸 이미지, 실시간 상황 텍스트, 욕구, 관계, 대화와 기억이 표시됩니다. 이번 버전은 기존 방 이미지와 초상화를 재사용하며, 행동별 신규 이미지 생성은 포함하지 않습니다.
- 말 걸기, 함께 식사, 도시락 건네기, 정리 돕기, 메시지 남기기를 버튼 또는 입력으로 제안합니다. 성격과 관계에 따라 거절할 수 있습니다.
- 수면·샤워·외출 중에는 메시지만 남길 수 있습니다. 여유가 생기면 읽고 답장을 보냅니다. 읽음과 친밀감 변화는 한 번만 적용됩니다.
- 함께한 기억과 대화는 자동 저장·내보내기·불러오기에 포함됩니다. 기존 저장 파일을 계속 사용할 수 있습니다.
- 입주 심사, 수리·중재·시설 개선, 생활 기록, 빈방 임대 조건, 시간 제어를 제공합니다.

## 실행

Node.js 20.12 이상에서 추가 패키지 설치 없이 실행합니다.

```sh
npm start
```

http://127.0.0.1:4173 에서 플레이합니다. 1×는 실제 18초마다 게임 10분입니다. 4×와 일시 정지, 다음 아침 이동을 지원합니다. 창을 닫아둔 시간은 다음 접속 시 최대 게임 7일까지 계산합니다. 일시 정지 상태는 유지됩니다.

현재는 브라우저 로컬 저장을 사용하는 개인 플레이 버전입니다. 계정 로그인, 클라우드 게임 저장, 멀티플레이는 포함하지 않습니다. AI 호출만 별도 서버를 사용합니다.

## OpenRouter 연결

토큰 없이도 기본 대화와 명령으로 플레이할 수 있습니다. 기본 모드의 자유 입력은 보수적으로 해석합니다. 예: `안녕하세요`, `같이 밥 먹자`, `도시락 건네기`, `정리 도와주기`, `메시지 남기기`. 지원하지 않는 요청은 상태를 바꾸지 않습니다.

1. `.env.example`을 로컬 `.env`로 복사합니다.
2. `OPENROUTER_API_KEY`와 선택한 정확한 모델 ID인 `OPENROUTER_MODEL`을 설정합니다.
3. 서버를 다시 시작합니다. 게임의 저장과 설정에서 연결 상태를 확인할 수 있습니다.

키는 서버 환경에서만 읽습니다. `.env`는 Git에서 제외되고 HTTP로 제공되지 않습니다. 유료 기본 모델은 지정하지 않습니다. 두 값이 모두 있어야 AI 요청을 보냅니다. 모델이 JSON 모드를 지원하면 선택적으로 `OPENROUTER_RESPONSE_FORMAT=json`을 설정할 수 있습니다. 기본값은 프롬프트 기반 JSON 출력이며, 두 모드 모두 응답을 검증합니다.

버튼 행동은 게임 규칙으로 먼저 적용한 뒤 대사만 AI로 다듬습니다(최대 1회). 자유 입력은 지원되는 행동으로 분류한 뒤 같은 규칙을 적용합니다(최대 2회). 모델은 게임 상태를 직접 쓰지 않습니다. 대기 중에도 세계는 진행하며, 입력 해석 후 현재 입주자와 행동 가능 여부를 다시 확인합니다. 초기화·불러오기 이후의 늦은 응답은 버립니다.

AI에 전달하는 정보와 공개 서버 구성은 위 0.9 항목을 참고하세요. 로컬 서버는 20초 시간 제한, 서버당 분당 20회·동시 2회 제한을 둡니다. 공개 서버는 IP별 분당 12회·인스턴스별 분당 24회·동시 2회로 제한하며 세션 발급도 횟수에 포함합니다. 연결 실패·지원하지 않는 형식은 기본 반응으로 이어갑니다.

서버는 127.0.0.1에만 바인딩하고 API의 Host와 Origin을 확인합니다. 이 구조를 공용 서비스로 노출하려면 별도의 인증, 사용자별 저장 및 사용량 제한이 필요합니다.

참고: [OpenRouter Chat Completions](https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion), [Structured Outputs](https://openrouter.ai/docs/guides/features/structured-outputs).

- `index.html`, `horizon.css`, `horizon-app.js`: 도시 전경, 얼굴 타일, 툴팁, 방 상세와 개입 화면

- `sim.js`: 자율 생활, 출퇴근·관계·계약·건물 운영, 오프라인 진행과 저장 검증
- `http-server.mjs`, `openrouter.mjs`, `server.mjs`: 로컬 서버와 OpenRouter 연결
- `cast.js`, `cast-ready.js`, `scripts/`: 입주자 이미지 풀(30명)과 생성 스크립트
- `midnight.css`, `fx.js`: 다크 모드 UI와 인터랙션 효과

모든 입주자는 가상의 성인입니다. 이미지 출처와 생성 기록은 `assets/LIVE-ASSETS.md`, `assets/RESIDENCE-CREDITS.md`, `assets/cast/PROMPTS.md`를 참고하세요. 도시 배경은 내장 ImageGen으로 만든 실사 용산 블루아워 이미지입니다. 생성 기록은 `assets/ROMANTIC-ART.md`에 있습니다. 폰트는 Pretendard 공식 CDN을 사용하며 오프라인에서는 시스템 폰트로 대체됩니다.

## 입주자 사진첩

방의 **사진 보기**(또는 방 사진의 `촬영` 버튼)에서 장면을 입력하면 `qwen/qwen-image-2.1-turbo`가 기존 입주자 프로필을 참조해 사진 1장을 생성합니다. 프로필과 생성 사진은 클릭하면 확대됩니다. 생성 사진은 게임 저장과 별도로 이 브라우저의 IndexedDB에 입주자별 최근 12장까지 보관되며, 저장 파일 내보내기에는 포함되지 않습니다.

OpenRouter Image API `/api/v1/images`는 서버의 `/api/photo`를 통해서만 호출합니다. 참조 이미지는 서버에서 허용한 기존 여성 캐스트 파일로 제한하고, 키는 브라우저에 전달하지 않습니다. 향후 게임 이미지 생성/편집 모델은 `AGENTS.md` 지침에 따라 Qwen Image 2.1 Turbo를 사용합니다.

### 대화와 사진의 표현 범위

성인 간 연애·호감·친밀감과 비노골적인 속옷/란제리 패션 대화를 지원합니다. 사진의 속옷/란제리는 불투명한 의상과 중립적인 포즈의 비성적 패션 표현으로 한정하며, 노출·성행위·성적 포즈는 허용하지 않습니다. 현재 착용 속옷은 저장된 게임 상태가 아니므로 AI가 실제 착용 정보를 안다고 꾸며내지 않습니다. 이미지 제공업체 자체 정책에 따라 일부 요청은 거절될 수 있습니다.

얼굴 타일은 각 원본에서 감지·검수한 얼굴 중심의 정사각 크롭, 상세 프로필은 상반신 크롭을 사용합니다. `srcset`으로 화면 크기와 픽셀 밀도에 맞춰 WebP를 선택합니다. 원본 파일은 유지하며 `assets/portraits/crops.json`에 좌표를 기록했습니다. Pillow가 있는 환경에서 `python scripts/build-portraits.py`로 재생성할 수 있습니다. 원본 크기가 바뀌면 좌표를 다시 검수해야 합니다.

R19 파비콘은 글꼴에 의존하지 않는 SVG 심볼이며 16·32·48·64px ICO도 제공합니다.
